# data/

Carpeta para guardar los insumos de cada proceso de inscripción de electivos
cuando estén disponibles: oferta de electivos (por ejemplo, el *Plan de
Formación Diferenciada* del año), nóminas de estudiantes, exportaciones de
Lirmi, diccionarios de asignaturas, respaldos, etc.

El contenido de esta carpeta **no se versiona** (ver `.gitignore`); solo este
README queda en el repositorio. Tampoco se copia a la imagen Docker.

Convención sugerida: incluir el año en el nombre del archivo
(`Plan de Formación Diferenciada 2027.pdf`, `nomina_2027.csv`, ...).
